## Features

- Calculators for Circuit Repair and Floating Recovery puzzles in *Arknights: Endfield*.

## Development

Node.js 22 · npm 10

```sh
npm ci
npm run dev
```

## Build & deploy

```sh
npm run build
```

Output: `dist/`, for static hosting at the domain root.

```sh
npm run preview
```
